# Admin Panel

Панель администратора Free Mine.

## Запуск

Требуется Node.js 24.13.1–24.x или Docker Compose.

1. Создайте `.env` на основе `.env.example`, если файл ещё не создан. Заполните `RPC_URL` **только на сервере**. Для чтения данных и проверки планов `PRIVATE_KEY` можно оставить пустым; для выполнения операций нужен ключ текущего владельца OreVein. Панель ключ и RPC URL не запрашивает.
2. Выполните `docker compose pull backend`, чтобы получить актуальный образ сервера.
3. Выполните `docker compose up --build -d`.
4. Откройте <http://localhost:5175> или <http://127.0.0.1:5175>. Панель подключается автоматически: REST использует адрес страницы, WebSocket — `localhost` с тем же портом и выбором WS/WSS по HTTP/HTTPS. nginx проксирует оба соединения на `backend:3000`. Отдельной настройки URL нет.

Панель совместима с `admin-server@d05445b`; Compose использует образ `ghcr.io/free-mine/admin-server`. Бекенд по умолчанию слушает `0.0.0.0:3000`; порт `3000` и каталог `/app/data` фиксированы. Переменные `PORT`, `DATA_DIR` и `ALLOWED_ORIGINS` больше не используются — удалите их из старого `.env`. `HOST` остаётся доступен, но для Compose менять его не требуется. Панель опубликована только на локальном интерфейсе.

Адрес страницы не меняется. Бекенд принимает Origin `http://localhost` и `https://localhost` с любым портом. Браузер берёт Origin из адреса страницы независимо от адреса WebSocket, поэтому nginx преобразует только локальные Origin с `127.0.0.1` и `[::1]` в `localhost`, сохраняя схему и порт. Остальные Origin передаются без изменений и проверяются бекендом. Это одинаково работает в readonly и в режиме выполнения операций.

Постоянный volume для бекенда не используется: `/app/data` размещён в `tmpfs` с правами пользователя `node`. Это также перекрывает объявленный в образе `VOLUME`, чтобы Docker не создавал анонимный том. Журнал существует только пока контейнер работает; после остановки или перезапуска очередь и история операций пусты, а актуальные балансы и состояние контрактов заново читаются через RPC.

Журнал нужен для продолжения незавершённых многошаговых операций и распознавания повторного запроса после потери ответа. Например, после approve сервер мог отправить обмен, но ещё не получить receipt. Без журнала новый экземпляр не узнает этот план, его хэш транзакции и оставшиеся шаги. Уже отправленная транзакция всё ещё может подтвердиться. Поэтому перед остановкой сервера с ключом завершите операции; после неожиданной остановки проверьте транзакции владельца перед повторением действий. Для readonly этих незавершённых операций нет.

Для разработки:

```sh
npm ci
npm run dev
```

Vite доступен на <http://localhost:5173> и проксирует API через Compose на порт 5175. Если сервер недоступен, панель показывает статус и автоматически повторяет подключение каждые 15 секунд. Готовность подтверждается через `/ready`, а не только `/health`.

В режиме readonly панель показывает данные, события и предварительные планы операций. Выполнение, повторная отправка и принятие внешней замены транзакции недоступны. Режим определяется по `readOnly` в `/v1/config` и `/ready` и обновляется при проверке готовности. Отсутствующий, пустой, некорректный или чужой ключ оставляет сервер в readonly.

## Возможности панели

- **Фонд:** текущая и предыдущая смены, просмотр любой смены по ID, диапазоны открытых заявок, финансирование, закрытие смены и просроченных заявок, цена входа, расчётный токен и URI контракта.
- **Капитал:** балансы OreVein и отдельный газ владельца; внесение, вывод, заём и погашение Aave; обмен LFJ; создание, пополнение, сбор средств, вывод ликвидности и удаление пустого NFT Uniswap.
- **Операции:** предварительный план с параметрами, разрешениями, комиссией и сроком действия; явное подтверждение; очередь, статусы шагов, receipts и фактический газ. Для `needs_attention` доступна проверка подтверждённой внешней замены.
- **Преемники:** расписание, назначение, перенос даты и удаление. Время отображается и вводится в МСК (UTC+3).

Суммы передаются десятичными строками; расчёты выполняются через `BigInt`. В балансах и суммах капитала отображаются до 8 знаков после запятой без округления. Кнопка рядом копирует полную сумму с точкой и без разделителей разрядов. Неполная оценка газа обозначена отдельно. При ошибках сохраняется последний успешный снимок с датой; при потере готовности новые записи блокируются. WebSocket восстанавливается автоматически, REST обновляется каждые 15 секунд.

Перед отправкой в локальном хранилище браузера сохраняется пара `previewId` / `requestId`. Если ответ потерян, «Проверить отправку» повторяет эту же пару, в том числе после перезагрузки страницы. Восстановление результата возможно, пока сервер сохраняет журнал; перезапуск контейнера с `tmpfs` его стирает. Пока результат не выяснен, новая операция не открывается. Истечение или изменение плана требует нового просмотра и подтверждения. Закрытие страницы не отменяет уже поставленную в очередь операцию.

## Проверки

```sh
npm run build
npm run lint
npm run format:check
npm test
```

Тесты используют изолированный API в Playwright: ключ, RPC и работающий бекенд не нужны. На Windows используется установленный Edge; на других системах установите Chromium командой `npx playwright install chromium`. Браузер можно переопределить через `PLAYWRIGHT_CHANNEL`. Vite для тестов запускается автоматически. Артефакты проверок находятся в игнорируемой `.tmp/`.

Покрыты точность денежных сумм, параметры всех 18 действий, отсутствие отправки до подтверждения, восстановление потерянного ответа, истечение и изменение плана, пропуски заявок, ошибки чтения, обновления операций и адаптивность на 390, 900 и 1440 px. Реальные транзакции требуют отдельной проверки с настроенным бекендом.

На каждом pull request GitHub Actions параллельно запускает `Lint` (ESLint, Stylelint и Prettier), `Tests` (Playwright с Chromium) и `Build` (TypeScript и production-сборка). Версия Node.js берётся из `engines.node` в `package.json`, зависимости устанавливаются через `npm ci`. Новый коммит отменяет предыдущий запуск этого PR.

В CI тесты выполняются в один worker, а `test.only` запрещён. HTML-отчёт с трассировками упавших тестов сохраняется в артефакте `playwright-report` на 7 дней. После скачивания и распаковки откройте его командой `npx playwright show-report <папка-отчёта>`. Секреты и работающий бекенд для CI не требуются. Версии GitHub Actions закреплены по SHA; Dependabot еженедельно проверяет их обновления.

## Структура

`app` запускает приложение и глобальные стили. `pages/console` владеет рабочим пространством, его API-контрактами, состоянием и сценариями. `shared` содержит HTTP-транспорт, точное преобразование чисел, графику, шрифты и общие токены оформления. Все внешние импорты проходят через публичные входы модулей; реализации и стили страницы остаются внутри её слайса. Каталог `design` сохранён как исходный референс.
