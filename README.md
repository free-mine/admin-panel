# Admin Panel

Панель администратора Free Mine (https://github.com/free-mine/contracts, 5b7bd28).

Данный репозиторий запускает в Docker Compose бекенд (https://github.com/free-mine/admin-server, f47be58) и собственный фронтенд.

## Запуск

Требуется Node.js 24.13.1–24.x или Docker Compose.

1. Создайте `.env` на основе `.env.example`, если файл ещё не создан. Заполните `RPC_URL` и `PRIVATE_KEY` **только на сервере**. Панель их не запрашивает.
2. Проверьте `ALLOWED_ORIGINS`: для Docker нужен `http://127.0.0.1:5175`, для разработки — `http://127.0.0.1:5173`. При использовании `localhost` добавьте его отдельным origin.
3. Выполните `docker compose up --build -d`.
4. Откройте <http://127.0.0.1:5175>. Адрес API по умолчанию совпадает с адресом панели: nginx проксирует REST и WebSocket на `backend:3000`.

Бекенд должен слушать `0.0.0.0:3000`, как в `.env.example`. Журнал операций хранится в постоянном volume `backend-data`. Панель доступна только на локальном интерфейсе. Контракт API реализован по `admin-server@f47be58`; Compose использует образ `ghcr.io/free-mine/admin-server`, поэтому при обновлении образа нужно сохранять совместимость с этой версией API.

Для разработки:

```sh
npm ci
npm run dev
```

Vite доступен на <http://127.0.0.1:5173> и проксирует API через Compose на порт 5175. Можно также указать отдельный адрес API на экране «Подключение»; сервер должен разрешать origin страницы. Готовность подтверждается через `/ready`, а не только `/health`.

## Возможности панели

- **Фонд:** текущая и предыдущая смены, просмотр любой смены по ID, диапазоны открытых заявок, финансирование, закрытие смены и просроченных заявок, цена входа, расчётный токен и URI контракта.
- **Капитал:** балансы OreVein и отдельный газ владельца; внесение, вывод, заём и погашение Aave; обмен LFJ; создание, пополнение, сбор средств, вывод ликвидности и удаление пустого NFT Uniswap.
- **Операции:** предварительный план с параметрами, разрешениями, комиссией и сроком действия; явное подтверждение; очередь, статусы шагов, receipts и фактический газ. Для `needs_attention` доступна проверка подтверждённой внешней замены.
- **Преемники:** расписание, назначение, перенос даты и удаление. Время отображается и вводится в МСК (UTC+3).

Суммы передаются десятичными строками; расчёты выполняются через `BigInt`. Неполная оценка газа обозначена отдельно. При ошибках сохраняется последний успешный снимок с датой; при потере готовности новые записи блокируются. WebSocket восстанавливается автоматически, REST обновляется каждые 15 секунд.

Перед отправкой в локальном хранилище браузера сохраняется пара `previewId` / `requestId`. Если ответ потерян, «Проверить отправку» повторяет эту же пару, в том числе после перезагрузки страницы. Пока результат не выяснен, новая операция не открывается. Истечение или изменение плана требует нового просмотра и подтверждения. Закрытие страницы не отменяет уже поставленную в очередь операцию.

## Проверки

```sh
npm run build
npm run lint
npm test
```

Тесты используют изолированный API в Playwright: ключ, RPC и работающий бекенд не нужны. На Windows используется установленный Edge; на других системах установите Chromium командой `npx playwright install chromium`. Браузер можно переопределить через `PLAYWRIGHT_CHANNEL`. Vite для тестов запускается автоматически. Артефакты проверок находятся в игнорируемой `.tmp/`.

Покрыты точность денежных сумм, параметры всех 18 действий, отсутствие отправки до подтверждения, восстановление потерянного ответа, истечение и изменение плана, пропуски заявок, ошибки чтения, обновления операций и адаптивность на 390, 900 и 1440 px. Реальные транзакции требуют отдельной проверки с настроенным бекендом.

## Структура

`app` запускает приложение и глобальные стили. `pages/console` владеет рабочим пространством, его API-контрактами, состоянием и сценариями. `shared` содержит HTTP-транспорт, точное преобразование чисел, графику, шрифты и общие токены оформления. Все внешние импорты проходят через публичные входы модулей; реализации и стили страницы остаются внутри её слайса. Каталог `design` сохранён как исходный референс.
