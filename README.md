# Admin Panel

Панель владельца фонда Free Mine на SolidJS: управление сменами OreVein, капиталом, операциями и преемниками. Бекенд — `ghcr.io/free-mine/admin-server` с PIN-сессиями (`/v1/session`) и локальным журналом (`/v1/journal`).

## Запуск

Требуется Docker Compose. Создайте `.env` на основе `.env.example`:

| Переменная       | Назначение                                                                                                                          |
| ---------------- | ----------------------------------------------------------------------------------------------------------------------------------- |
| `RPC_URL`        | HTTP(S) RPC Avalanche C-Chain.                                                                                                      |
| `ALLOWED_DOMAIN` | Единственное разрешённое имя хоста: `localhost` или собственный домен. Без схемы, порта, пути, завершающей точки, списка или маски. |
| `PANEL_PIN`      | PIN-код из 4–32 цифр; начальные нули сохраняются. Задайте своё значение вместо пустого в `.env.example`.                            |
| `PRIVATE_KEY`    | Ключ текущего владельца OreVein для выполнения операций. Без подходящего ключа доступно только чтение и проверка планов.            |

Все переменные, кроме `PRIVATE_KEY`, обязательны. PIN, ключ кошелька и RPC URL передаются только бекенду.

```sh
docker compose pull backend
docker compose up --build -d
```

При `ALLOWED_DOMAIN=localhost` откройте <http://localhost:5175> и введите PIN. Для собственного домена настройте его разрешение в адрес панели. Другие имена, включая поддомены и `127.0.0.1`, отклоняются; порт не ограничивается.

Compose публикует панель только на локальном интерфейсе. nginx проксирует REST и WebSocket на `backend:3000`; бекенд проверяет домен в `Host` и `Origin`. Для удалённого доступа используйте HTTPS reverse proxy, сохраняющий эти заголовки.

Вход выдаёт HttpOnly cookie на 12 часов. Выход отзывает сессию; перезапуск бекенда сбрасывает все сессии. Правила входа и ограничения попыток описаны в [документации сервера](https://github.com/free-mine/admin-server#домен-и-вход).

При обновлении старого `.env` добавьте `ALLOWED_DOMAIN` и `PANEL_PIN`, удалите `PUBLIC_SERVER_URL` и `PUBLIC_SERVER_KEY`. Для Compose оставьте `HOST=0.0.0.0` по умолчанию.

## Данные и восстановление

Полный журнал новых операций, включая завершённые, хранится локально в `/app/data/operations.json` в volume `backend-data`. Сохраняйте volume при обновлении: `docker compose down --volumes` удаляет его вместе с журналом; обычные `stop`, `restart` и `down` сохраняют. При переходе со старого контейнера перенесите его журнал из `/app/data` в volume.

Старый `operations.pending.json` читается при миграции: сохраняются записи, которые ещё находились локально. Ранее удалённая локально история с публичного сервера автоматически не загружается. Разделы панели читают данные через RPC; запросов к публичному серверу больше нет. Раздел «Операции» показывает ошибки локального журнала через `/v1/journal`. В режиме только чтения журнал не изменяется.

При потере ответа используйте «Проверить отправку»: панель сохраняет идентификаторы запроса в браузере и повторяет его без дублирования операции, в том числе после перезагрузки страницы. До выяснения результата новая операция недоступна. После перезапуска бекенда, истечения срока или изменения неподтверждённого плана нужны новый просмотр и подтверждение. Закрытие страницы не отменяет поставленную в очередь операцию.

## Возможности

- **Фонд:** смены и заявки, финансирование и закрытие, цена входа, расчётный токен и URI контракта.
- **Капитал:** балансы OreVein и газ владельца; внесение, вывод, заём и погашение Aave; обмен LFJ; создание и обслуживание позиций Uniswap.
- **Операции:** предварительный план и подтверждение, очередь, шаги, receipts и фактический газ. Для `needs_attention` — проверка подтверждённой внешней замены.
- **Преемники:** назначение, перенос даты и удаление. Время вводится и отображается в МСК (UTC+3).

Для позиции Uniswap задайте суммы обоих активов и минимальное расстояние до границ. Сервер подбирает диапазон; план показывает границы, ожидаемые суммы и остатки. Ограничения описаны в [API](https://free-mine.github.io/admin-server/).

Балансы и суммы капитала показываются с точностью до 8 знаков без округления; копирование сохраняет полную сумму. При ошибках остаётся последний успешный снимок с датой, новые операции блокируются при потере готовности сервера. Данные обновляются по WebSocket и каждые 15 секунд через REST.

## Разработка и проверки

Требуется Node.js 24.13.1–24.x. Vite на <http://localhost:5173> проксирует API через Compose на порт 5175.

```sh
npm ci
npm run dev
```

```sh
npm run build
npm run lint
npm test
```

Playwright подменяет API и запускает Vite; работающий бекенд не нужен. На Windows используется установленный Edge, на других системах установите Chromium: `npx playwright install chromium`. Браузер переопределяется через `PLAYWRIGHT_CHANNEL`. Артефакты находятся в `.tmp/`; реальные транзакции эти тесты не проверяют.

CI выполняет те же проверки; отчёт с трассировками доступен в артефакте `playwright-report`.
